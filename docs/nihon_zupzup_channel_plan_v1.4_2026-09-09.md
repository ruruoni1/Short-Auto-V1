# 니혼줍줍 채널 운영 계획서 v1.4
작성일: 2026-09-09

## 1. 채널 기본 방향

### 채널명
니혼줍줍

### 핵심 포지셔닝
**보다 보면 일본어가 쌓이는 채널**

니혼줍줍은 전통적인 문법/JLPT 중심 일본어 강의 채널이 아니라,
일본 콘텐츠와 실제 생활 속에서 발견되는 흥미로운 표현, 말투, 문화 차이를
쉽고 재미있게 설명하는 채널을 지향한다.

핵심 원칙:
> 이 콘텐츠를 본 사람이 일본어 또는 일본의 언어문화를 하나라도 줍게 되는가?

YES → 제작 가능  
NO → 원칙적으로 제작하지 않음

---

## 2. 장기 확장 방향

니혼줍줍은 단순 일본어 학습 채널이 아니라,
장기적으로 다음 순서로 확장 가능한 구조를 목표로 한다.

단어
→ 표현
→ 상황
→ 언어문화
→ 애니/일드/게임 해설
→ 일본문화

단, 모든 확장의 시작점은 항상 **언어 또는 표현**이어야 한다.

예시:

- 오사카 맛집 TOP10 → 비추천
- 오사카 식당에서 실제로 듣게 되는 간사이벤 → 추천

- 일본 편의점 신제품 리뷰 → 비추천
- 일본 편의점 직원이 계산할 때 실제로 하는 말 → 추천

- 애니 추천 TOP10 → 비추천
- 애니에서 왜 이 캐릭터만 이런 말투를 쓸까? → 추천

## 3. 콘텐츠 6대 축

### 3.1 애니 줍줍
역할: 신규 시청자 유입

주요 소재:
- 애니에서 자주 나오는 단어
- 캐릭터별 말투
- 오레/보쿠/와타시 차이
- 츤데레 표현
- 악역/야쿠자 말투
- 중2병 표현
- 시대극 표현
- 애니와 실제 일본어의 차이

### 3.2 일드 줍줍
역할: 자연스러운 현실 회화

주요 소재:
- 직장 일본어
- 전화 표현
- 연애 표현
- 가족 대화
- 상사/후배 말투
- 서비스업 표현
- 형사/의학/법정 드라마 표현

### 3.3 실전 줍줍
역할: 채널의 중심 학습 콘텐츠

주요 소재:
- 여행
- 편의점
- 음식점
- 호텔
- 쇼핑
- 전철
- 택시
- 회사
- 전화
- 생활 회화
- 한국인이 흔히 오해하는 일본어

### 3.4 영어 줍줍
역할: 재미 + 차별화

주요 소재:
- 와세이에이고
- 영어와 의미가 달라진 일본어
- 외래어
- 일본식 영어 발음

대표 예:
- マンション(만숀) = 아파트/공동주택
- コンセント(콘센토) = 전기 콘센트
- テンション(텐숀) = 기분/흥분도
- クレーム(쿠레무) = 불만/항의
- ペーパードライバー(페파 도라이바) = 장롱면허

### 3.5 사투리 줍줍
역할: 언어문화 + 캐릭터성

초기 집중:
- 간사이벤

확장:
- 교토
- 하카타
- 히로시마
- 나고야
- 도호쿠
- 오키나와 등

기본 포맷:
표준어 → 사투리 → 느낌 차이

예:
本当？(혼토?)
→ ほんま？(혼마?)

### 3.6 한본어/트렌드 줍줍
역할: 최신성 + 트렌드 감지

주요 소재:
- 일본에서 쓰이는 한국어
- K-pop 영향
- 일본 SNS 신조어
- 젊은 층 표현
- 일본 인터넷 용어
- 새로운 외래어
- 세대별 표현 차이

## 6. Shorts 전략

Apify를 이용해 일본어 학습 채널의 구독자 대비 조회수, 좋아요, 댓글, 영상 길이를 조사한 결과,
Shorts는 하나의 포맷으로 통일하지 않는 것이 좋다고 판단했다.

### 6.1 반복/암기형 Shorts
역할:
- 조회수
- 반복재생
- 즉시 학습
- 초보자 유입

권장 비중:
**약 50%**

권장 길이:
**5~20초**

예시:
大丈夫
다이죠부
괜찮아

大丈夫？
다이죠부?
괜찮아?

특징:
- 빠른 소비
- 반복재생에 유리
- 댓글은 적을 수 있음
- 조회수 확보에 강할 가능성

### 6.2 발견/반전/차이형 Shorts
역할:
- 채널 차별화
- 댓글/호기심 유발
- 롱폼 주제 발굴

권장 비중:
**약 30%**

권장 길이:
**20~35초**

예시:
- 일본에서 맨션에 산다면 부자일까?
- 오이시와 우마이는 뭐가 다를까?
- 혼토와 혼마는 어떻게 다를까?
- 야바이는 상황마다 왜 뜻이 달라질까?

기본 흐름:
질문
→ 반전
→ 표현
→ 의미
→ 비교
→ 짧은 정리

### 6.3 문화/사투리/애니/한본어 실험형 Shorts
역할:
- 바이럴 가능성 탐색
- 차별화
- 새로운 카테고리 테스트

권장 비중:
**약 20%**

예시:
- 간사이벤
- 애니 캐릭터 말투
- 일본인이 쓰는 한국어
- 세대별 표현
- 문화 차이

예:

  - 조회수 약 156,115
  - 좋아요 391

  - 길이 5초

- 동물 이름
  - 조회수 약 81,576

## 8. Shorts 성과 판단 지표

조회수만으로 판단하지 않는다.

### VIRAL SCORE
조회수 ÷ 구독자 수

의미:
채널 규모를 넘어 얼마나 확산되었는가

### SATISFACTION SCORE
좋아요 ÷ 조회수

의미:
시청자의 적극적인 만족도 추정

### DISCUSSION SCORE
댓글 ÷ 조회수 × 1,000

의미:
1,000뷰당 댓글 수
주제가 얼마나 대화/질문을 만들었는지 추정

### 댓글 내용
특히 중요.

댓글에서:
- 추가 질문
- 표현 차이 질문
- 실제 사용 사례
- 반박/논쟁
- 다른 표현 요청

이 많이 나오면 롱폼 후보로 우선 검토한다.

## 9. Long-form 전략

롱폼은 한 종류로 운영하지 않는다.

### 9.1 Discovery Long-form
권장 길이:
**8~18분**

역할:
- 조회수
- 구독
- 브랜드 구축
- 주제 심화

주요 유형:
- 문제 해결형
- 이유 설명형
- 문화 차이형
- 애니/일드/사투리 분석
- 일본어의 구조와 배경

예:
- 일본인은 왜 영어를 이렇게 바꿔 사용할까?
- 애니 일본어를 현실에서 쓰면 왜 이상할까?
- 오사카 사람은 정말 이렇게 말할까?
- 오이시와 우마이는 실제로 어떻게 구분할까?

### 9.2 Training Long-form
권장 길이:
**20~60분 이상**

역할:
- 반복학습
- 듣기/말하기 훈련
- 재방문
- Watch Time 축적 가능성

예:
- 일본 여행 필수 회화 50문장 반복듣기
- 식당에서 실제로 듣는 일본어 30분 훈련
- 일상 일본어 쉐도잉
- 사투리 듣기 훈련

## 10. Long-form 조사에서 확인된 주요 패턴

### 10.1 설봉의 문제 해결형 롱폼
「당신이 일본어 회화가 안 느는 이유, 이렇게 해야 늡니다」

- 구독자 약 8,960
- 조회수 약 220,708
- 구독자 대비 약 24.6배
- 좋아요 약 6,600
- 좋아요율 약 2.99%
- 댓글 447
- 1,000뷰당 댓글 약 2.03
- 길이 17분 29초

판단:
단순 조회수뿐 아니라
좋아요와 댓글까지 매우 강한 고품질 반응형 롱폼.

니혼줍줍 롱폼의 중요한 벤치마크:
> 단순 강의 제목보다 문제/질문형 제목이 강할 가능성

예:
- 일본어 회화 공부법 10가지 → 약함
- 왜 일본어 회화가 늘지 않을까? → 강함

### 10.2 들리는 일본어tv 반복형 롱폼

「실생활 일본어 50문장 반복듣기」
- 조회수 약 29,852
- 좋아요 807
- 댓글 25
- 길이 42분 35초

「기초 일본어 표현 150문장」
- 조회수 약 43,014
- 좋아요 1,000
- 댓글 34
- 길이 1시간 40분 53초

「일본 여행 쇼핑편 필수 일본어 50문장」
- 조회수 약 23,975
- 좋아요 704
- 댓글 18
- 길이 40분 43초

판단:
조회수 폭발형이라기보다
반복 시청, 학습, 긴 시청시간 확보용 자산일 가능성이 높다.

공개 데이터로 실제 평균 시청시간과 평균 시청률은 확인할 수 없으므로
Watch Time 성과는 추정만 가능하다.

## 11. 외부에서 확인 불가능한 YouTube Analytics 데이터

Apify 및 공개 YouTube 데이터로는 아래 지표를 확인할 수 없다.

- 총 시청 시간
- 평균 시청 지속 시간
- 평균 시청률
- 첫 30초 유지율
- 구간별 이탈 그래프
- 노출수
- CTR
- 재방문 시청자
- Shorts → Long-form 실제 전환율
- 엔드스크린 클릭률
- 관련 영상 클릭률

따라서 경쟁 채널은 공개 지표로 추정하고,
니혼줍줍 자체 채널에서는 YouTube Analytics를 이용해 실제 데이터를 확인한다.

## 12. Shorts와 Long-form 연결 전략

가장 중요한 원칙:

> **같은 내용을 반복하지 않는다.**

Shorts:
**“뭐지?”**

Long-form:
**“왜 그렇지?” / “어떻게 쓰지?”**

### 잘못된 방식
월: 맨션
수: 콘센트
금: 텐션
일: 세 쇼츠를 그대로 길게 다시 설명

문제:
이미 쇼츠를 본 시청자에게 새 가치가 적다.

### 권장 방식

월 Shorts:
マンション(만숀)

수 Shorts:
コンセント(콘센토)

금 Shorts:
テンション(텐숀)

일 Long-form:
**일본인은 왜 영어를 이렇게 바꿔 사용할까? 와세이에이고의 세계**

롱폼에서는:
- 추가 단어
- 역사/배경
- 영어권과 의미 차이
- 실제 사용 상황
- 문화적 이유

까지 확장한다.

즉:
Shorts = 사례
Long-form = 이유와 구조

## 13. 반복형 Shorts와 Long-form 연결

반복형은 설명형 롱폼보다
Training Long-form으로 연결한다.

예:

Shorts:
일본 식당 필수 5문장

→

Long-form:
일본 식당 입장부터 계산까지 실제 대화 30분 듣기

구조:
Shorts = 암기
Long-form = 훈련

## 14. 발견형 Shorts와 Long-form 연결

발견형 Shorts는 Discovery Long-form 후보를 찾는 센서로 사용한다.

예:

Shorts:
우마이 써도 될까?

댓글:
- 오이시와 차이는?
- 여자도 우마이라고 하나?
- 회사에서 써도 되나?
- 애니에서는 왜 자주 나오나?

→

Long-form:
**오이시와 우마이, 일본인은 실제로 어떻게 구분해서 쓸까?**

롱폼 확장:
- 남녀 차이
- 세대 차이
- 상황 차이
- 애니/일드 사례
- 실제 회화

---

## 15. 조회수 높은 Shorts가 항상 롱폼 후보는 아니다

예:
5초짜리 음식 일본어가 15만 조회를 기록했더라도
좋아요율과 댓글률이 매우 낮다면
단순 소비형 콘텐츠일 가능성이 높다.

이 경우:
- 같은 유형 Shorts 추가 제작 → 추천
- 즉시 심층 롱폼화 → 우선순위 낮음

반대로 조회수가 조금 낮아도
댓글과 질문이 많이 생기는 콘텐츠는
롱폼 후보 가치가 높다.

## 20. 영상 화면/대본 기본 원칙

4. 한국어 독음
5. 뜻/비교
6. 정리

### 일본어 표기
일본어를 읽지 못하는 한국인도 볼 수 있게:

**일본어 + 한국어 독음 + 의미**

예:
やばい(야바이)
대박 / 위험하다 / 큰일이다 등

### 톤
피해야 할 말:
- 오늘 배워볼 표현은
- 이번 시간에는
- 외워보도록 하겠습니다

권장 톤:
- 이 말, 애니에서 많이 들어봤죠?
- 그런데 실제 뜻은 조금 다릅니다.
- 일본에서는 이런 상황에서 자주 씁니다.

화자 포지션:
**전문가가 가르친다기보다 같이 재미있는 일본어를 발견하는 사람**

## 25. 현재 최종 전략 요약

### Shorts의 역할
**유입 + 테스트 + 학습**

- 반복형으로 조회수를 확보
- 발견형으로 브랜드를 구축

**이해 + 관계 + 학습 자산**

- Discovery Long-form으로 깊이 있는 이유와 문화를 설명
- Training Long-form으로 반복학습과 듣기 훈련 제공

### 핵심 연결 공식
Shorts에서:
> “이게 뭐지?”

Long-form에서:
> “왜 그런지, 실제로 어떻게 쓰는지”

### 채널 궁극적 목표
> 일본어 공부하러 온 것은 아닌데,
> 보다 보니 일본어가 늘었다.

## 28. 초기 채널 런칭 방식

채널 초기에 콘텐츠가 1편만 존재해 채널 홈이 비어 보이는 문제를 줄이되,
여러 편을 한 번에 대량 공개하지 않는다.

### 기본 원칙

- **제작은 최소 2주치를 미리 준비**
- **공개는 하루 1편 수준으로 순차 공개**
- 첫 롱폼을 먼저 공개한 뒤, 관련 Shorts를 후속 공개하여 처음부터 `관련 동영상`으로 연결한다.
- 첫 주 안에 Long-form 2편 + Shorts 3~4편 이상이 쌓이도록 한다.

### 권장 초기 흐름

**Day 1 — 일요일**
- Long-form 1편 공개

**Day 2 — 월요일**
- 관련 Shorts 1편
- 관련 동영상 → Long-form 1

**Day 3 또는 Day 4**
- 관련 Shorts 1편
- 관련 동영상 → Long-form 1

**Day 5 또는 Day 6**
- 독립 실험형 Shorts 1편

**Day 7 — 다음 일요일**
- Long-form 2편 공개

이후 정상 주간 일정으로 전환한다.

### 초기 운영에서 피해야 할 것

- 첫날 Shorts와 Long-form을 6~10편씩 한꺼번에 공개
- 첫 롱폼 없이 Shorts만 먼저 여러 편 공개하여 관련 동영상 연결을 못 하는 구조
- 콘텐츠가 준비되지 않은 상태에서 일정만 맞추기 위해 공개

---

## 29. 초기 Shorts → Long-form 연결 방향

초기에는 아직 니혼줍줍 자체 데이터가 없으므로,
**Long-form을 먼저 만들고 그 안에서 Shorts 소재를 뽑는 방식**을 우선한다.

### 초기 단계

Long-form
→ 관련 Shorts 2편
→ 독립 실험 Shorts 1편

예:

Long-form:
**일본인은 왜 영어를 이렇게 바꿔 사용할까?**

파생 Shorts:
- マンション(만숀)
- コンセント(콘센토)

독립 테스트 Shorts:
- 本当(혼토) vs ほんま(혼마)

### 데이터 축적 이후

데이터가 쌓이면 다음 순환 구조로 전환한다.

독립 Shorts 테스트
→ 반응 좋은 주제 발견
→ Long-form 제작
→ Long-form에서 추가 Shorts 파생
→ 관련 동영상으로 다시 Long-form 유입

즉 최종 구조:

**Shorts → Long-form → Shorts → 다음 Long-form**

## 30. 업로드 시간 초기 운영 지침

경쟁 일본어 채널 공개시간 조사와
한국 시청자 생활 패턴을 참고하여 초기 시간대를 다음과 같이 설정한다.

### 1~4주차 기본 시간

- **일요일 Long-form: 18:00 KST**
- **월요일 Shorts: 18:30 KST**
- **수요일 Shorts: 18:30 KST**
- **금요일 Shorts: 18:30 KST**

초기 4주 동안은 시간을 자주 바꾸지 않는다.

목적:
- 주제 차이와 시간 차이를 혼동하지 않기 위함
- 비교 가능한 초기 표본 확보
- 일정한 시청 습관 형성

### 오전 시간대 테스트 후보

반복/암기형 Shorts는
출근·등교 시간대와 궁합이 좋을 가능성이 있으므로
2차 테스트에서 **08:00 KST**를 후보로 사용한다.

예:
- 월 반복/암기형 Shorts → 08:00
- 수 발견/반전형 Shorts → 18:30
- 금 롱폼 연계형 Shorts → 18:30
- 일 Long-form → 18:00

단, 초기 4주에는 기본적으로 18:30에 고정한다.

## 31. 4주 테스트 / 8주 전략 확정 체계

니혼줍줍의 초기 운영은 **4주마다 조정하고, 8주마다 큰 방향을 판단**한다.

### 4주 = 조정 주기

4주 운영 기준 예상 콘텐츠:
- Shorts 약 12편
- Long-form 약 4편

4주차 종료 시 확인:
- Shorts 유형별 성과
- 주제별 성과
- 구독자 대비 조회수
- 좋아요율
- 댓글률
- 댓글 내용
- Long-form 성과
- Shorts → Long-form 연결 가능성
- 업로드 시간대 초기 반응

### 4주차 이후 수정 가능 항목

- 반복형 Shorts 비중
- 발견형 Shorts 비중
- 문화/사투리/애니 실험 비중
- Long-form Discovery / Training 비중
- Shorts 길이
- Long-form 길이
- 제목 형식
- 업로드 시간
- 오전 08:00 테스트 여부
- 관련 동영상 연결 방식

### 5~8주차

1~4주차 데이터를 반영한 수정 전략으로 다시 4주 운영한다.

예:
- 반복형 Shorts 일부를 오전 08:00 테스트
- 댓글 반응이 강한 주제를 Long-form으로 확대
- 저반응 주제 비중 축소
- 강한 카테고리의 후속 콘텐츠 집중

### 8주 = 전략 확정 주기

8주차 종료 시
1차 4주와 2차 4주를 비교한다.

최종 판단:
- 핵심 콘텐츠 축
- Shorts 최적 비율
- Long-form 최적 비율
- 주간 편성
- 업로드 시간
- Long-form 길이
- Shorts → Long-form 퍼널 방식
- 확대해야 할 주제
- 축소해야 할 주제

핵심 원칙:

> **4주 = 조정**
>
> **8주 = 전략 확정**

니혼줍줍 자체 데이터가 28일 이상 축적되면
YouTube Studio의:

**시청자 → 시청자가 YouTube를 이용하는 시간**

데이터를 우선한다.

우선순위:

1. 니혼줍줍 자체 시청자 데이터
2. 영상 유형별 실제 성과
3. 업로드 직후 초기 반응
4. 경쟁 채널 업로드 시간
5. 일반적인 유튜브 권장 시간

장기적으로는
Shorts와 Long-form을 같은 시간대에 고정할 필요가 없다.

가능한 최종 형태:

- 반복형 Shorts → 오전 08:00
- 발견/반전형 Shorts → 저녁 18:30~20:00
- Long-form → 일요일 18:00~19:00

단, 실제 자체 데이터가 이를 지지할 때만 적용한다.

## 35. 애니·일드 공식 클립 소스 전략 — 2026-09-09 확정

니혼줍줍의 애니·일드 콘텐츠는 Nadeshiko 등 외부 대사/클립 서비스 중심으로 운영하지 않는다.

핵심 소스 파이프라인:

> **공식 YouTube 채널 → YouTube Data API 수집 → 로컬 클립 DB → 후보 분석/검수 → 채택 영상만 yt-dlp 확보**

### 역할 분리

**YouTube Data API**
- 공식 채널 관리
- 최신 영상/Shorts 동기화
- 제목/설명/업로드일/통계/썸네일/video_id 수집

**yt-dlp**
- 채택된 영상만 다운로드
- 가능한 자막/자동자막 확보
- 실제 제작용 미디어 관리

### 초기 공식 소스 우선순위

애니 S:
- Aniplex
- TOHO animation

애니 A:
- Toei Animation
- KADOKAWA Anime
- 작품별 공식 채널

일드 S:
- 日テレドラマ公式

일드 A:
- TBS
- フジテレビ
- テレビ東京
- テレビ朝日

### 작품/대사 판단 순서

> **실제 대사 정확성 → 문맥 적합성 → 공식 클립 확보 가능성 → 작품 인지도·최신성**

### 두 가지 소재 발굴 루트

1. **표현 우선**: 찾고 싶은 표현 → 내부 공식 클립 DB 검색 → 장면 검증
2. **클립 우선**: 공식 채널 최신 클립 → 재미있는 표현 자동 탐색 → 콘텐츠 후보화

공식 YouTube 영상은 출처가 명확한 소스이지 자유 이용 소스가 아니다. 실제 사용은 해설·분석 목적에 필요한 최소 범위를 원칙으로 한다.

## 36. 니혼줍줍 관리 프로그램 — 공식 클립 라이브러리 모듈

기존 콘텐츠 플랜 관리 기능에 다음 모듈을 포함한다.

### 공식 채널 관리
- 공식 YouTube 채널 등록/수정/비활성화
- 애니/일드 분류
- 소스 우선순위 S/A/B

- 제목/표현/작품/채널 검색
- 후보 상태 관리

### 후보 상태

`NEW → ANALYZED → REVIEWED → CANDIDATE → SELECTED → DOWNLOADED`

- Shorts 후보
- Discovery Long-form 후보

- 일드 줍줍 후보

로 보낼 수 있도록 설계한다.
