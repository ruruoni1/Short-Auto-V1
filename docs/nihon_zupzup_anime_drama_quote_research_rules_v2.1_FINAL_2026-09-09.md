# 니혼줍줍 애니·일드 대사 조사 및 작품 선정 지침 v2.1 FINAL

작성일: 2026-09-09  
적용 대상: 니혼줍줍 애니·일드 기반 콘텐츠 리서치 및 대본 제작  
상태: 최종 운영 기준본  
이전 버전: v1.0 (Nadeshiko 중심 조사 방식)

# 1. 문서 목적

이 문서는 니혼줍줍에서 애니·일드의 실제 대사를 조사하고,
그중 어떤 작품과 대사를 콘텐츠에 사용할지 선정하는 기준을 정리한 운영 지침이다.

v2.1은 v2.0의 공식 YouTube 중심 구조를 유지하며 썸네일 프레임 연계를 추가한다.

v2.0 핵심 변경은 다음과 같다.

- Nadeshiko 중심 조사 방식 폐기
- **공식 YouTube 실제 클립 중심**으로 전환
- **YouTube Data API + yt-dlp + 로컬 DB**를 핵심 파이프라인으로 사용
- 공식 클립 확보 가능성을 작품/대사 선정의 핵심 요소로 추가
- 표현 우선 탐색과 공식 클립 우선 탐색을 병행
- 외부 대사/클립 서비스는 필수 의존성에서 제외

---

# 2. 최상위 원칙

> **대사 정확성과 문맥이 먼저다. 그다음은 공식 클립 확보 가능성, 작품 인기·최신성이다.**

최종 판단 순서:

> **실제 대사 정확성**
> → **문맥 적합성**
> → **공식 클립 확보 가능성**
> → **작품 인지도·최신성**

인기 작품이라는 이유만으로 부적절한 대사를 억지로 사용하지 않는다.

---

# 3. 기본 조사 흐름

## 방식 A — 표현 우선

1. 조사할 표현 또는 말투를 정한다.
2. 내부 공식 클립 DB에서 먼저 검색한다.
3. 제목/설명/자막/전사에서 실제 대사 후보를 확보한다.
4. 공식 YouTube 원본을 직접 연다.
5. 작품명·화수·영상 유형을 확인한다.
6. 앞뒤 문맥과 캐릭터 관계를 확인한다.
7. 일본어 원문을 확정한다.
8. 한국어 독음을 작성한다.
9. 자연스러운 의미와 뉘앙스를 검증한다.
10. 작품의 인기·최신성을 확인한다.
11. 대사 적합도 + 소스 확보성 + 작품 가중치를 비교한다.
12. 최종 사례를 선정한다.

## 방식 B — 공식 클립 우선

1. 등록된 공식 YouTube 채널의 최신 영상을 수집한다.
2. `scene / highlight / short / cutout` 후보를 자동 분류한다.
3. 제목/설명/자막에서 흥미로운 일본어 표현을 찾는다.
4. AI가 콘텐츠 후보를 제안한다.
5. 사람이 실제 장면과 문맥을 검수한다.
6. 좋은 표현을 Shorts/Long-form 주제 후보로 등록한다.

# 4. 공식 YouTube 소스 원칙

애니·일드 실제 장면은 가능한 경우 **권리자/제작사/배급사/방송사가 운영하는 공식 YouTube 채널**을 우선한다.

초기 우선 소스:

- Aniplex — S
- TOHO animation — S
- Toei Animation — A
- KADOKAWA Anime — A
- 작품별 공식 채널 — A/B

## 일드
- 日テレドラマ公式 — S
- TBS — A
- フジテレビ — A
- テレビ東京 — A
- テレビ朝日 — A

실제 채널 ID와 활성 상태는 별도 소스 설정/DB에서 관리한다.

---

# 5. 공식 채널 검증

다음 중 여러 신호를 확인한다.

- 방송사/제작사/배급사 공식 사이트에서 연결된 채널
- YouTube 인증/공식 브랜드 정보
- 작품 공식 홈페이지에서 연결된 채널
- 채널 설명 및 운영 주체

팬 업로드, 불명확한 재업로드, 클립 모음 채널은 기본 소스로 등록하지 않는다.

# 6. 클립 유형 우선순위

대사 조사에 우선:

1. `scene` — 본편 실제 장면
2. `cutout` — 切り抜き
3. `highlight` — 에피소드 하이라이트
4. `short` — 공식 Shorts
5. `preview` — 선행 공개
6. `digest` — 다이제스트

낮은 우선순위:
- PV
- Trailer
- CM
- OP/ED
- 인터뷰
- 행사 영상

일본어 학습 목적에서는 `ENGLISH DUB` 등 일본어 원음이 아닌 버전을 기본 후보에서 제외한다.

---

# 7. 대사 후보 수

표현 우선 조사에서는 첫 결과를 바로 채택하지 않는다.

기본:
> 최소 3개 후보

권장:
> 3~5개 후보

다만 공식 클립 자체가 희소한 경우에는 후보 수보다 **정확한 실제 장면 검증**을 우선한다.

---

# 8. 대사 자체의 선정 기준

## 1순위 — 표현 정확성
설명하려는 표현이 실제 대사에 정확히 포함되어 있어야 한다.

## 2순위 — 문맥 적합성
설명하려는 뉘앙스와 실제 장면의 관계/감정/상황이 맞아야 한다.

## 3순위 — 공식 클립 확보성
원본 YouTube URL이 명확하고 실제 장면을 직접 확인할 수 있어야 한다.

## 4순위 — 대사 이해 용이성
복잡한 설정 없이 시청자가 이해하기 쉬운 사례를 우선한다.

## 5순위 — 캐릭터 관계 명확성
친구/상사/부하/적/가족/연인/선후배 등의 관계를 설명하기 쉬운가?

## 6순위 — 작품 관심도
동급 후보라면 최신·인기·인지도 높은 작품을 우선한다.

---

# 9. 작품 분류 체계

## Tier A — NOW
현재 방영 중이거나 최근 공개된 인기 작품.

## Tier B — EVERGREEN
시점과 관계없이 높은 대중적 인지도를 가진 작품.

## Tier C — DISCOVERY
인지도는 상대적으로 낮아도 일본어 사례가 매우 좋은 작품.

중요:
> Tier는 대사 적합도를 뒤집는 절대 조건이 아니다.

---

# 10. 소스 확보 가능성의 의미

`공식 클립 확보 가능성`은 다음을 의미한다.

- 실제 장면이 공식 YouTube에서 확인 가능
- 원본 URL이 보존 가능
- 작품명/화수 또는 장면 출처를 검증 가능
- 필요한 경우 채택 후 yt-dlp로 제작용 로컬 원본을 확보 가능

공식 YouTube에 없다고 해서 표현 자체를 폐기할 필요는 없지만,
초기 니혼줍줍 제작에서는 **쉽게 검증·확보할 수 있는 후보를 우선**한다.

# 11. YouTube Data API / yt-dlp 역할 분리

## YouTube Data API
- 공식 채널 동기화
- 영상 ID/제목/설명/날짜/통계/썸네일 수집
- 신규 영상 탐지
- 메타데이터 DB 저장

## yt-dlp
- `SELECTED` 된 영상의 미디어 처리
- 가능한 자막/자동자막 저장
- 상세 포맷/메타데이터 확인
- 로컬 원본 저장

규칙:
> 모든 수집 영상을 다운로드하지 않는다.

---

# 12. Nadeshiko의 위치 변경

Nadeshiko는 v2.0부터 핵심 조사 도구가 아니다.

문제:
- 스크린샷이 대사 장면을 정확히 대표하지 않는 경우가 있음
- 영상 형태의 결과가 실제 원작 클립 확보 목적과 맞지 않음
- 콘텐츠 제작 소스 확보까지 이어지는 워크플로가 약함

따라서 필요 시 **보조 검색 자료**로 참고할 수는 있으나,
프로그램/운영의 필수 의존성으로 두지 않는다.

Nadeshiko 개별 Sentence 링크 확보도 더 이상 필수 조건이 아니다.

---

# 13. Jimaku/기타 자막 DB의 위치

외부 자막 DB는 필요 시 수동 보조 조사에 사용할 수 있다.

그러나:
- 프로그램 필수 의존성으로 두지 않는다.
- 공식 원본 검증을 대신하지 않는다.
- 팬 자막/자동 자막의 오류 가능성을 직접 검증한다.

자막 DB보다 자체 공식 클립 라이브러리와 공식 YouTube 원본을 우선한다.

---

# 14. 실제 대사와 언어 설명의 역할 분리

애니·일드 대사:
> 실제 사용 사례 증명

사전/언어학/일본어 교육 자료:
> 뜻·뉘앙스·역사·현실 사용법 검증

한 장면만으로 일본어 전체의 사용법을 일반화하지 않는다.

---

# 15. 번역 규칙

자동 번역이나 영어 번역을 그대로 재번역하지 않는다.

확인:
- 일본어 원문
- 앞뒤 문맥
- 화자/청자
- 캐릭터 관계
- 장면 상황
- 표현 뉘앙스

필요 시 직역/자연스러운 번역/실제 뉘앙스를 구분한다.

---

# 16. 한국어 독음 규칙

기본 자료:

> 일본어 원문 + 한국어 독음 + 자연스러운 의미

독음은 기계적인 문자 치환보다 실제 청취 발음에 가깝게 적는다.

# 18. 시청자용 대본과 제작 자료 분리

## 제작자용
- 작품명
- 화수

- 원문/독음/의미

- 검증 상태

- 저작권/Content ID 메모

# 21. 최종 제외 조건

- 공식 채널 여부가 불명확
- 실제 장면이 아님
- 작품명/화수 검증 실패
- 대사 원문 불확실
- 문맥이 설명과 다름
- 번역/뉘앙스를 확신할 수 없음
- 캐릭터 관계를 오해할 가능성이 큼
- 유명 작품이라는 이유만으로 억지 선정
- 잘라내면 원래 의미가 달라짐

핵심:
> **모르면 제외한다.**

# 23. 최종 운영 공식

> **표현 우선 또는 공식 클립 우선 탐색**
> → **공식 YouTube 후보 확보**
> → **작품·화수·실제 대사·문맥 검증**
> → **대사 정확성 + 문맥 + 소스 확보성 평가**
> → **작품 인기·최신성 가중치 적용**
> → **사람 최종 검수**
> → **채택된 영상만 yt-dlp로 확보**
> → **시청자용 대본 + 제작자용 자료 분리**

# 26. 썸네일 후보 프레임 연계 — v2.1 추가

특정 작품/캐릭터/대사가 콘텐츠 훅인 경우, 대사 검증 단계에서 **썸네일 후보 프레임**도 선택적으로 기록한다.

추가 메타데이터:
- `thumbnail_frame_candidate`
- `frame_timestamp`
- `frame_reason`
- `rights_review_status`

프레임 선정 기준:
- 말하는 캐릭터 또는 핵심 관계가 명확함
- 표정/상황이 콘텐츠 질문과 맞음
- 배경만 보이는 프레임 제외
