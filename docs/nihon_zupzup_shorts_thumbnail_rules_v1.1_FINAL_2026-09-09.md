# 1. 문서 목적

이 문서는 니혼줍줍 Shorts 영상의 썸네일 제작 기준을 정리한 최종 운영 문서다.

니혼줍줍 Shorts는 채널 운영 계획상 다음 세 가지 역할로 운영한다.

1. **반복/암기형 Shorts**
2. **발견/반전/차이형 Shorts**
3. **문화/사투리/애니/일드/한본어 실험형 Shorts**

다만 썸네일 디자인은 지나치게 많은 유형으로 나누지 않고, 다음 두 가지 기본 템플릿으로 단순화한다.

1. **Shorts Discovery**
2. **Shorts Learning**

문화/사투리/애니/일드/한본어 실험형은 별도 템플릿을 만들지 않고 **Shorts Discovery의 변형**으로 운영한다.

# 2. 최종 운영 구조

## TYPE A — Shorts Discovery

역할:
- 신규 시청자 유입
- 호기심 유발
- 반전/차이 전달
- 댓글/질문 유도
- Long-form 후보 주제 탐색
- 니혼줍줍 브랜드 차별화

적합한 콘텐츠:
- 발견/반전/차이형 Shorts
- 사투리
- 애니/일드 말투
- 한본어
- 신조어
- 문화 차이
- 오해하기 쉬운 표현

핵심 메시지:
> **이게 왜 이 뜻이지? / 진짜 이렇게 쓰나? / 내가 알던 의미와 다른데?**

대표 훅 예:
- 만숀이 아파트?
- 우마이 써도 돼?
- 혼마가 진짜?
- 현실에선 이상해?
- 일본인이 진짜 써요
- 일본에서만 통해요

---

## TYPE B — Shorts Learning

역할:
- 반복 학습
- 즉시 암기
- 초보자 유입
- 표현 반복재생
- 짧고 빠른 학습 경험

적합한 콘텐츠:
- 반복/암기형 Shorts
- 여행 표현
- 일상 회화
- 짧은 생활 표현
- 한 단어/한 문장 학습

핵심 메시지:
> **이 표현을 바로 기억하고, 듣고, 따라 할 수 있는가?**

대표 훅 예:
- 다이죠부?
- 오이시!
- 혼토?
- 아리가토!
- 야바이!

# 3. 최상위 원칙

> **한 썸네일 = 한 아이디어**

모든 Shorts 썸네일은 다음 원칙을 따른다.

- 핵심 메시지는 하나만 보여준다.
- 일본어를 읽지 못해도 이해 가능해야 한다.
- 한국어 또는 한국어 독음이 클릭 메시지의 중심이다.
- 일본어 원문은 소재/증거/학습 요소로 사용한다.
- 모바일에서 1초 안에 핵심이 보여야 한다.
- 로고보다 메시지가 우선한다.
- 설명문을 넣지 않는다.
- 오브젝트나 인물은 기본적으로 1개만 사용한다.
- 제목과 썸네일이 같은 문장을 그대로 반복하지 않게 한다.
- 쇼츠의 첫 화면과 썸네일이 자연스럽게 이어지도록 설계한다.

# 4. 언어 표기 원칙

니혼줍줍은 일본어를 읽지 못하는 한국인도 볼 수 있는 채널을 지향한다.

따라서 Shorts 썸네일에서도 일본어 원문만으로 핵심 훅을 만들지 않는다.

기본 우선순위:

## 1순위 — 한국어 또는 한국어 독음

예:
- 만숀
- 다이죠부
- 혼마
- 우마이
- 야바이

## 2순위 — 한국어 질문/반전 문구

예:
- 아파트?
- 써도 돼?
- 진짜?
- 현실에선 이상해?

## 3순위 — 일본어 원문

예:
- マンション
- 大丈夫
- ほんま
- うまい
- やばい

일본어 원문은 작게 보여도 되며, 메인 훅을 방해하지 않는다.

# 5. 텍스트 길이 규칙

Shorts는 Long-form보다 더 빠르게 읽혀야 한다.

기본 권장:
> **1~4어절**

예:
- 만숀이 아파트?
- 다이죠부?
- 우마이 써도 돼?
- 혼마가 진짜?
- 현실에선 이상해?

피해야 할 것:
- 질문 + 설명 + 뜻 + 독음 + 예문을 한 장에 모두 넣기
- 긴 문장
- 영상 내용을 썸네일에서 모두 설명하기

# 6. Shorts Discovery 최종 공식

- 보조: 일본어 원문

예:

# 8. Shorts Discovery 기본 샘플 01 — 확정

파일:
> `푸른_하늘과_현대_아파트_광고_포스터.png`

주제:
> 와세이에이고 / マンション

메인 훅:
> **만숀이 아파트?**

보조:
> マンション

시각 요소:
> 일본의 일반적인 공동주택 1개

최종 평가:
> **확정**

확정 이유:
- 메인 문구가 정확하고 가독성이 좋음
- 일본어를 몰라도 메시지가 이해됨
- 오브젝트가 하나로 정리됨
- 일본어 원문은 보조 역할에 머묾
- 9:16 세로형에서 모바일 가독성이 좋음
- Long-form Discovery와 디자인 언어가 크게 충돌하지 않음
- 별도 로고나 라벨 없이도 메시지가 명확함

운영 기준:
- 블루 계열 배경 사용 가능
- 노랑은 핵심 단어 포인트로만 사용
- 깊은 그림자 지양
- 건물 또는 대표 오브젝트는 화면 하단~중앙에 크게 배치
- 텍스트와 오브젝트 사이에 충분한 여백 확보

# 9. Shorts Learning 최종 공식

- 보조: 일본어 원문
- 시각: 표현의 상황을 직관적으로 보여주는 인물 1명

예:

메인:
> **다이죠부?**

보조:
> 大丈夫

시각:

# 10. Shorts Learning 시각 요소 규칙

권장:
- 인물 1명
- 자연스러운 표정
- 표현의 의미와 맞는 제스처
- 얼굴이 모바일에서도 충분히 크게 보이도록 배치

좋은 감정:
- 궁금함
- 듣는 표정
- 가벼운 놀람
- 미소
- 자연스러운 반응

피해야 할 것:
- 과장된 충격 표정
- 입을 크게 벌린 클릭베이트 표정
- 무관한 감정
- 여러 명의 인물

# 11. Shorts Learning 기본 샘플 01 — 확정

파일:
> `다이죠부_따뜻한_일본어_표현_포스터.png`

주제:
> 大丈夫(다이죠부)

메인 훅:
> **다이죠부?**

보조:
> 大丈夫

시각 요소:
> 귀를 기울이는 자연스러운 인물 1명

최종 평가:
> **확정**

확정 이유:
- 인물의 시선과 손동작이 표현의 상황과 잘 맞음
- 메인 한글 독음이 강하게 읽힘
- 일본어 원문은 보조 역할로 적절함
- 크림 + 노랑 계열이 반복학습형 콘텐츠와 잘 어울림
- 장식이 과하지 않음
- Discovery와 성격은 다르지만 채널 전체 톤과 충돌하지 않음

운영 기준:
- 크림/웜톤 계열 배경 사용 가능
- 노랑은 포인트 또는 배경 도형에 제한적으로 사용
- 배경 도형은 인물보다 강하게 보이지 않게 한다.
- 메인 텍스트와 인물은 중앙 안전영역에 집중한다.
- 일본어 원문은 메인 텍스트보다 한 단계 작게 배치한다.

# 12. Discovery와 Learning 차이

| 항목 | Shorts Discovery | Shorts Learning |
|---|---|---|
| 목적 | 호기심/클릭 | 즉시 학습/암기 |
| 메시지 | 질문·반전·차이 | 표현 자체 |
| 메인 텍스트 | 질문형 중심 | 독음/표현 중심 |
| 일본어 원문 | 보조 증거 | 학습 보조 |
| 이미지 | 오브젝트 또는 상황 | 인물 1명 권장 |
| 분위기 | 발견/궁금증 | 친근/학습 |
| 대표 색감 | 블루 계열 | 크림/노랑 계열 |
| 정보량 | 매우 적음 | 매우 적음 |

# 13. 실험형 Shorts 적용 방식

사투리, 애니, 일드, 한본어, 문화 콘텐츠는 별도 썸네일 템플릿을 만들지 않는다.

기본적으로 Shorts Discovery를 사용한다.

예:

간사이벤:
> 혼마가 진짜?

애니 말투:
> 현실에선 이상해?

한본어:
> 일본인이 진짜 써요

일드 직장 표현:
> 상사는 이렇게 말한다

애니/일드 실험형 중 **특정 작품·캐릭터·대사가 클릭 훅인 경우에는 해당 작품의 실제 장면 이미지를 적극 우선 검토한다.**

우선순위:
1. 내부 공식 YouTube 클립 라이브러리에서 검토한 실제 장면 프레임
2. 작품/제작사/방송사 공식 YouTube 클립의 프레임
3. 자체 제작/재현 이미지
4. AI 보조 이미지

반대로 언어 개념 자체가 훅이거나 여러 작품을 비교하는 경우에는 특정 작품 이미지에 억지로 묶지 않는다.

# 14. 로고 사용

기본 원칙:
> **Shorts 썸네일에 니혼줍줍 로고를 넣지 않는다.**

브랜드는 다음 요소로 구축한다.

- 문구 구조
- 여백
- 타이포그래피
- 일본어 표기 방식
- 색감
- 인물/오브젝트 배치

---

# 15. 첫 화면과 썸네일 연결 원칙

Shorts는 썸네일만 따로 설계하지 않는다.

기본 흐름:

> 썸네일 → 첫 프레임 → 1~2초 훅

예:

썸네일:
> 만숀이 아파트?

첫 화면:
> 일본에서 “맨션에 살아요”라고 하면...

다음 화면:
> 우리가 생각하는 맨션이 아닙니다.

즉 썸네일과 첫 화면이 같은 질문을 반복하는 것이 아니라, 자연스럽게 이어져야 한다.

# 16. 모바일 우선 검수

모든 Shorts 썸네일은 실제 YouTube 모바일 크기로 축소해 확인한다.

검수 질문:

1. 1초 안에 핵심이 보이는가?
2. 일본어를 몰라도 이해되는가?
3. 메인 문구가 너무 길지 않은가?
4. 오브젝트 또는 인물이 한눈에 보이는가?
5. 일본어 원문이 메인보다 강하지 않은가?
6. 장식이 메시지를 방해하지 않는가?
7. Shorts 첫 화면과 자연스럽게 연결되는가?

# 24. v1.1 제작 아키텍처 — 무텍스트 베이스 + 텍스트 레이어

Shorts 썸네일도 AI가 글자를 그리게 하지 않는다.

> **텍스트 없는 베이스 이미지 → 별도 텍스트 오버레이 → 최종 합성**

- AI 이미지에는 한글/일본어/숫자/로고를 렌더링하지 않는다.
- 메인 훅과 일본어 원문은 별도 텍스트 레이어로 관리한다.
- Shorts 안전영역 가이드를 에디터에 표시한다.
- 텍스트 박스는 드래그/리사이즈 가능해야 한다.
- 프로젝트 파일을 보존해 문구 A/B 테스트와 재편집이 가능해야 한다.
